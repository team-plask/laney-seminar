# Laney 글쓰기

먼저 글의 독자와 용도를 확인하고, 필요한 참조만 읽습니다.

- 모든 글에는 [공통 글쓰기 원칙](references/writing-principles.md)을 적용합니다.
- 한국어 초안과 번역문, AI가 작성한 글을 다듬을 때에는 [자연스러운 한국어](references/korean-naturalness.md)를 함께 적용합니다.
- 고객이 읽는 UI, 메시지, 랜딩 페이지, 에이전트 답변에는 [고객 대면 문체](references/customer-voice.md)를 적용합니다.
- 공개 제품 가이드를 만들거나 고칠 때에는 [가이드 작성 규칙](references/guide-authoring.md)을 적용합니다.

새 글을 쓸 때에는 독자가 읽고 해야 할 일을 먼저 정합니다. 기존 글을 다듬을 때에는 사실,
수치, 고유명사, 직접 인용, 문서의 격식과 원래 목소리를 보존합니다. 발견한 문제만 고치고,
자연스러운 문장을 기계적인 평균 문체로 바꾸지 않습니다.

이 규칙을 채널이나 기능별 프롬프트에 복사하지 않습니다. 글을 만드는 스킬은 이 패키지에
의존하고, 해당 독자와 공개 범위, 결과물에만 필요한 차이를 자체 문서에 적습니다.
