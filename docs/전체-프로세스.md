# PHASE 0 · 세미나 전날까지 (운영자)

**이 세미나는 원장님이 현장에서 직접 회원가입하는 흐름이다.**
계정·조직을 미리 만들어 배포하지 않는다 — 가입 시 병원 이름으로 조직이 생기고
owner 권한이 자동 부여된다.

| # | 할 일 | 확인 |
|---|---|---|
| 1 | 가입 흐름 리허설 (조직+owner 자동 생성은 배포됨 — `48b28eb`) | 테스트 가입 1회: 가입→**메일 인증**→조직 생성→`entities__insert` 성공까지 |
| 1b | 원장님들께 공지: **메일함에 접근 가능한 상태로 오기** (노트북 또는 휴대폰) | 가입 확인 메일을 현장에서 눌러야 한다 |
| 2 | 참석 병원 홈페이지 전수 확인: **가격이 텍스트인가 이미지인가** | 이미지 병원은 명단에 표시 |
| 3 | 1교시 시연 병원의 배지 불일치 미리 확인 | 배지 숫자 ≠ 실제 개수 캡처 |
| 4 | 리허설 1회: **신규 가입부터** 설치→가입→수집→입력→테스트 | 승인창 0회, `/usage` 전후 기록 |
| 5 | 원장님 노트북 요건 **사전 공지 메일** 발송 — 아래 '사전 설치 안내' | 미설치자는 당일 30분 일찍 |
| 6 | 오프라인 설치 파일 USB 2~3개 준비 (Git for Windows + Claude Code 앱) | 행사장 와이파이 병목 대비 |

### 사전 설치 안내 (공지 메일 본문용)

세미나 전에 두 가지만 설치해 주세요. (약 5분)

1. **Claude Code 앱** — https://claude.com/claude-code 에서 다운로드 후 설치, Claude 계정 로그인까지.
2. **Windows 사전 설치** (Mac은 앱 설치만으로 충분) — PowerShell 한 번, 붙여넣기 한 번:
   1. 키보드 **Windows 키 → "PowerShell" 입력 → Enter**
   2. 아래 한 줄을 붙여넣고 Enter → 끝날 때까지 대기 (2~3분) → 창 닫기
      ```
      winget install --id Git.Git -e --source winget; irm https://claude.ai/install.ps1 | iex
      ```
      (Git for Windows + Claude CLI가 함께 설치됩니다)
   - winget이 없는 구형 Windows: https://git-scm.com/download/win 에서 받아
     **"Next"만 계속** 눌러 Git을 먼저 설치한 뒤, 위 명령의 뒷부분
     (`irm https://claude.ai/install.ps1 | iex`)만 실행하세요.

# PHASE 2 · 회원가입 + 연결 (10분)

### 2-1. 연결 시도 → 브라우저에서 회원가입

▷
```
Laney에 연결해줘
```

☞ 브라우저가 열린다. **여기서 회원가입한다:**
1. 회원가입 선택 → 이메일·비밀번호 입력
2. **병원 이름을 정확히 입력** — 이 이름으로 조직이 만들어지고, 챗봇·랜딩에 그대로 쓰인다
3. **확인 메일이 발송된다** — 메일함(휴대폰도 가능)에서 확인 링크를 누른다
4. 브라우저로 돌아와 로그인이 이어진다. 연결이 끊겼으면 다시 ▷ `Laney에 연결해줘`

> 강사 멘트: "방금 두 가지가 생겼습니다. 원장님 계정, 그리고 **병원의 빈 차트**(조직).
> 지금은 텅 비어 있습니다 — 오늘 우리가 채웁니다."

⚠ 이미 Laney 계정이 있는 원장님은 가입 대신 로그인.

### 2-2. 연결 확인

▷
```
연결 확인해줘. 우리 병원 이름이 뭐라고 나와?
```

☞ 방금 가입 때 입력한 병원 이름이 나오면 성공.
⚠ 다른 이름이 나오면 → 손 들기. 진행 금지.

### 2-3. 빈 조직 확인

▷
```
지금 우리 조직에 등록된 시술이랑 상품이 몇 개인지 알려줘
```

☞ **방금 만든 조직이므로 둘 다 0개.** (0이 아니면 손 들기 — 계정 혼선)

# PHASE 3 · 수집 (15분 + 대기 중 강의)

### 3-1. 시작

▷ 주소만 본인 병원으로 바꿔서:
```
우리 병원 홈페이지 https://우리병원.com 을 seminar-min 프로파일로 수집해줘
```

☞ 진행 로그가 흐른다: 홈페이지 확인 → 페이지 목록 발견 → 여러 갈래로 나눠 읽기.
무슨 일이 일어나나: 신입(Claude)이 프로토콜(스킬)을 들고 홈페이지 전체를 읽고,
읽은 원문을 **파일로 보관**하면서 시술·가격·FAQ를 추린다.

> 강사: 여기서 15분 대기 강의 (차트가 필요한 이유 — 대본 3교시).

### 3-2. 완료 확인

☞ 끝나면 숫자 요약이 나온다: "시술 N개, 질문 N개 수집" 류.
(안내자가 자동으로 안내판을 띄우지 않았으면 ▷ `다음 단계 알려줘`)

**직접 확인** — 본인 홈페이지를 열어 시술 하나의 가격을 골라 적어둔다.
예: 울쎄라 363,000원. **다음 Phase의 대조용이다.**

### 3-3. 실패 분기

| 증상 | ▷ 입력할 문장 |
|---|---|
| 시술이 0~몇 개만 나옴 (가격이 이미지) | `우리 홈페이지는 가격이 사진으로 되어 있어. 사진도 읽어서 가져와줘` |
| 5분 넘게 조용함 | `어디까지 됐는지 알려주고, 남은 것부터 이어서 해줘` |
| 홈페이지가 원래 얇음 | 정상. "적게 나온 게 정확한 것" — 챗봇은 그만큼만 답하고 나머지는 확인 안내 |
| **홈페이지가 아예 없음** | ▷ `홈페이지가 없는 병원이야. {지역} {병원 이름} 을 찾아서 수집해줘` — 강남언니·구글맵 기반으로 진행. 가격은 "강남언니 게시 기준"으로 답하게 됨. 네이버는 접근 차단이라 제외(정상) |

# PHASE 4 · Laney에 넣기 (5~10분)

### 4-1. 입력

▷
```
수집한 걸 Laney에 넣어줘.
엔티티랑 상품은 나눠서 동시에 진행하고, 넣은 다음에 이름이 안 깨졌는지 확인해줘
```

문장의 두 조건에 이유가 있다:
- "나눠서 동시에" → 시간 1/3 (실측 17분→5분)
- "이름이 안 깨졌는지 확인" → 전송 중 글자가 드물게 깨진다 (실측: 신데렐라→신데렉라).
  이 조건이 있으면 Claude가 넣은 걸 다시 읽어 대조·수리한다.

☞ 완료 시: "시술 N개, 상품 N개, 상담 지침 1개 입력" + 이름 검증 결과.

### 4-2. 눈으로 확인 — 대시보드 첫 방문

브라우저에서 **https://dashboard.laney.app** → 로그인 → 좌측 **상품** 메뉴.

☞ 방금 넣은 상품이 목록으로 보인다. 아까 적어둔 가격을 검색해서 대조.
"화면 속 이 숫자가, 이제 챗봇이 답하는 근거입니다."

# 부록 B · 안내자(seminar-guide)의 동작 방식 — 운영자용

- **확실히 발동**: 원장님이 "다음 단계 알려줘 / 이제 뭐 해 / 어디까지 됐어"를 칠 때.
- **대체로 발동**: 수집·입력이 끝난 직후 Claude가 스스로 안내판을 띄운다.
  다만 이것은 보장이 아니라 판단이므로, **강사가 단계 종료마다
  "다음 단계 알려줘 치세요"를 외치는 것이 운영상의 보증**이다.
