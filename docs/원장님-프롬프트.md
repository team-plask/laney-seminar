# 원장님이 입력하실 내용 — 단계별

터미널 명령과 Claude에게 말하는 문장을 구분했습니다.
**`/`로 시작하는 것만 명령**이고, 나머지는 그냥 말하듯 입력하시면 됩니다.

---

## 0단계 · 설치 (한 번만)

**Windows이신 경우 먼저** (Mac은 건너뛰세요) — PowerShell 한 번이면 됩니다:
Windows 키 → "PowerShell" 입력 → Enter → 아래 한 줄 붙여넣고 Enter → 대기 → 창 닫기

```
winget install --id Git.Git -e --source winget; irm https://claude.ai/install.ps1 | iex
```


Claude Code를 열고 아래를 **한 줄씩** 입력하세요.

```
team-plask/laney-seminar 마켓플레이스를 추가하고, laney-seminar 플러그인을 설치해줘
```

> 중간에 허용 버튼이 한두 번 뜨면 눌러주세요.

> 설치되면 Laney 연결도 함께 등록됩니다.

---

## 1단계 · 승인창 끄기

승인창이 계속 뜨면 진행이 끊깁니다. Claude에게 이렇게 말씀하세요.

```
~/.claude/settings.json 파일을 만들어줘. 내용은 이거야:
{ "permissions": { "defaultMode": "bypassPermissions" },
  "skipDangerousModePermissionPrompt": true }
```

> 딱 한 번 "허용"을 누르시면 그 뒤로는 안 뜹니다.
> Claude Code를 한 번 껐다 켜시면 확실히 적용됩니다.

---

## 2단계 · Laney 회원가입 + 연결

```
Laney에 연결해줘
```

> 브라우저가 열리면 **회원가입**하세요. (계정이 있으면 로그인)
> **병원 이름을 정확히 입력하세요** — 그 이름으로 병원 공간이 만들어집니다.
> 가입 후 **확인 메일**이 옵니다. 메일함에서 링크를 눌러주세요. (휴대폰도 됩니다)

가입이 끝나면:

```
연결 확인해줘. 우리 병원 이름이 뭐라고 나와?
```

> 방금 입력한 병원 이름이 나오면 성공입니다.

---

## 3단계 · 조직이 비어 있는지 확인

```
지금 우리 조직에 등록된 시술이랑 상품이 몇 개인지 알려줘
```

> **0개여야 정상입니다.** 다른 병원 데이터가 나오면 멈추고 담당자를 부르세요.
> 그 위에 덮어쓰면 챗봇이 엉뚱한 병원으로 답합니다.

---

## 4단계 · 수집 (약 15분)

```
우리 병원 홈페이지 https://우리병원.com 을
seminar-min 프로파일로 수집해줘
```

> 홈페이지 주소만 본인 병원 것으로 바꾸세요.
>
> **홈페이지가 없으시면** 이렇게 입력하세요:
> `홈페이지가 없는 병원이야. 부산 서면 ○○의원 을 찾아서 수집해줘`
> (강남언니 등에서 찾아 진행합니다. 가격은 강남언니에 올리신 기준으로 답하게 됩니다)
> 진행 상황이 화면에 계속 나옵니다. 기다리시면 됩니다.

수집이 끝나면 몇 개를 가져왔는지 알려줍니다.

---

## 5단계 · Laney에 넣기 (약 10분)

```
수집한 걸 Laney에 넣어줘.
엔티티랑 상품은 나눠서 동시에 진행하고,
넣은 다음에 이름이 안 깨졌는지 확인해줘
```

> "나눠서 동시에"가 중요합니다. 시간이 3분의 1로 줄어듭니다.

---

## 6단계 · 확인

```
울쎄라 가격 알려줘
```

우리 병원 가격이 나오면 성공입니다. 다른 것도 물어보세요.

```
주차 되나요?
```
```
일요일에도 하나요?
```
```
홈페이지에 없는 걸 물어볼게. 강아지도 시술 받을 수 있어?
```

> 마지막 질문에 **"확인이 어렵습니다"** 라고 답해야 정상입니다.
> 모르는 걸 지어내지 않도록 만들었습니다.

---

## 길을 잃으면 — 만능 문장

어느 단계에 있든 이 한 줄이면 됩니다.

```
다음 단계 알려줘
```

지금 어디까지 됐는지 확인하고, 다음 할 일·복사할 문장·확인 링크를
안내판으로 보여드립니다. **막히면 고민하지 말고 이 문장부터.**

---

## 문제가 생기면

**수집이 중간에 멈췄을 때**
```
어디까지 됐는지 알려주고, 남은 것부터 이어서 해줘
```

**이름이 이상하게 저장됐을 때**
```
저장된 이름이랑 원본이랑 대조해서 다른 게 있으면 고쳐줘
```

**다시 처음부터 하고 싶을 때**
```
지금 들어간 시술이랑 상품 전부 지우고 처음부터 다시 해줘
```

**가격이 안 나올 때**
```
우리 홈페이지는 가격이 사진으로 되어 있어. 사진도 읽어서 가져와줘
```

## 기억하실 것 하나

이 도구는 **홈페이지에 적힌 것만** 가져옵니다.
없는 건 만들지 않고, 없는 할인은 붙이지 않습니다.

챗봇이 "모르겠습니다"라고 답하는 건 고장이 아니라
**틀린 답을 하지 않도록 만든 결과**입니다.
