# Laney 세미나 — 우리 병원 챗봇 만들기

오늘 만드는 건 하나입니다. 우리 병원 홈페이지에 있는 시술과 가격을 그대로 알고,
없는 건 지어내지 않고 "확인 후 안내드리겠습니다"라고 답하는 상담 챗봇.

코딩은 없습니다. 아래 회색 상자를 순서대로 복사해서 붙여넣는 게 전부입니다.
상자에 마우스를 올리면 오른쪽 위에 복사 버튼이 생깁니다.

이 페이지는 강의 순서 그대로입니다. 0번부터 차례대로 내려오시면 됩니다.
어디서든 막히면 `다음 단계 알려줘` 한 줄이면 Claude가 위치를 잡아줍니다.

---

## 0. 시작 전 준비

**준비물** 노트북 · Claude Pro 또는 Max 로그인 · 우리 병원 홈페이지 주소 · 충전기

**Claude Code 데스크톱 앱**을 아직 안 받으셨다면 https://claude.com/claude-code
에서 받고, Claude 계정으로 로그인해 주세요. 로그인된 첫 화면이 뜨면 준비 끝입니다.

Windows 노트북은 앱을 받기 전에 한 단계가 더 있습니다. 키보드에서 Windows 키를
누르고 "PowerShell"을 입력해 파란 창을 연 다음, 아래 한 줄을 붙여넣고 Enter.
2~3분 걸리고, 끝나면 창은 닫으셔도 됩니다. Mac은 이 단계가 없습니다.

```powershell
winget install --id Git.Git -e --source winget; irm https://claude.ai/install.ps1 | iex
```

앱이 켜졌으면 바탕화면에 새 폴더를 하나 만들고(이름은 아무거나), 그 폴더로 세션을
여세요. 오늘 만드는 파일이 전부 여기 모입니다.

---

## 1. 도구 설치

Claude에게 말하듯 입력하면 알아서 설치합니다. 1~2분 걸립니다.

```
team-plask/laney-seminar 마켓플레이스를 추가하고, laney-seminar 플러그인을 설치해줘.
설치가 끝나면 어떤 스킬이 들어왔는지 알려줘.
```

스킬 여섯 개가 들어왔다고 나오면 성공입니다. 병원 홈페이지 수집, 레이니 입력,
레이니 구조 지식, 진행 안내, 문구 다듬기, 연습 데이터 — 이 여섯 개입니다.
이름을 외우실 필요는 없고, 말로 요청하면 맞는 스킬이 알아서 발동합니다.

## 2. 허용 버튼 그만 누르기

이대로 두면 단계마다 허용 버튼을 눌러야 해서 번거롭습니다. 한 번만 설정하면
그 뒤로는 안 뜹니다.

```
~/.claude/settings.json 파일을 만들어줘. 내용은 이거야:
{ "permissions": { "defaultMode": "bypassPermissions" },
  "skipDangerousModePermissionPrompt": true }
```

허용 버튼이 마지막으로 한 번 뜹니다. 누른 다음 **앱을 완전히 껐다가 다시 켜세요.**
같은 폴더로 세션을 다시 열면 됩니다.

## 3. Laney 가입하고 연결하기

```
Laney에 연결해줘
```

브라우저가 열립니다. 회원가입을 선택하고 이메일과 비밀번호를 만드세요.

**병원 이름은 정확하게 입력해 주세요.** 이 이름으로 병원 공간이 만들어지고,
챗봇과 홈페이지에 그대로 쓰입니다.

가입하면 확인 메일이 옵니다. 휴대폰 메일함에서 열어도 됩니다. 링크를 누르면
로그인 화면이 하나 뜨는데, 인증은 이미 끝난 것이니 그 창은 닫으셔도 됩니다.
Claude로 돌아와 다시 한 번 `Laney에 연결해줘`를 입력하면, 방금 만든 계정으로
로그인되면서 연결이 완료됩니다.

가입하는 순간 네 가지가 자동으로 생깁니다. 병원 공간, 원장님의 최고 관리자 권한,
홈페이지에 뜨는 웹 채팅, 그리고 홈페이지 주소까지. 별도 설정은 없습니다.

잘 됐는지 확인해봅시다.

```
연결 확인해줘. 우리 병원 이름이 뭐라고 나오는지, 그리고 지금 등록된 시술이랑
상품이 몇 개인지 알려줘.
```

병원 이름이 맞고 시술·상품이 0개면 정상입니다. 방금 만든 빈 공간이니까요.
0이 아니라면 진행하지 말고 손을 들어주세요.

---

## 4. 첫 프롬프트 — 계획부터 받기

여기서부터가 본 실습입니다. 바로 만들라고 하지 않고 **계획부터** 받습니다.

가능하면 입력창에서 **계획 모드**로 바꾸세요. 키보드 Shift+Tab을 여러 번 누르면
모드가 바뀝니다. 못 찾아도 괜찮습니다. 아래 문장 자체가 계획부터 세우게 되어
있습니다.

병원 이름과 홈페이지 주소만 본인 것으로 바꿔서 입력하세요:

```
지금부터 레이니(Laney)로 우리 병원의 상담 챗봇과 홈페이지를 만들려고 해.

우리 병원: ○○의원 (부산 서면)
홈페이지: https://우리병원.com

바로 실행하지 말고, 먼저 이렇게 해줘:
1. 레이니가 어떤 구조인지, 챗봇이 되려면 최소한 뭐가 필요한지 파악하고
2. 지금 내 레이니 연결 상태와 병원 공간이 비어 있는지 확인해줘
3. 그다음 데이터를 어디서 모아서, 무엇을, 어떤 순서로 넣을지 전체 계획을 세워줘

계획에는 단계마다 예상 시간과, 끝났을 때 내가 눈으로 확인할 것을 같이 적어줘.
지켜야 할 원칙: 홈페이지에 적힌 것만 쓰고, 가격은 글자 그대로 옮기고,
챗봇은 모르는 걸 절대 지어내지 않아야 해.
계획을 보여주면 내가 읽고 승인한 다음에 시작하자.
```

(홈페이지가 없으면 `홈페이지: 없음, 강남언니에서 찾아줘` 로 바꾸세요)

계획이 나오면 읽어보세요. 대략 이런 모양이면 정상입니다:
홈페이지 수집(15분) → 수집 결과 검증 → 가격표와 챗봇 성격 입력(5분) →
챗봇 테스트 → 홈페이지 링크 → 말투 다듬기.

이상한 단계가 있으면 그 자리에서 "이건 왜 해?"라고 물으면 되고, 마음에 들면:

```
좋아, 계획대로 진행해줘. 단계가 끝날 때마다 결과를 보여주고 이어가.
```

이제 Claude가 알아서 진행합니다. 아래 5~9번은 계획대로 자동으로 흘러가는
내용이라, 중간에 확인하거나 직접 시키고 싶을 때만 쓰시면 됩니다.

중간에 궁금한 건 언제든 물어보세요. "레이니가 뭐야?", "엔티티가 뭔데?",
"지금 어디까지 됐어?" 전부 답합니다.

## 5. 우리 병원 수집 (15분)

계획대로 진행 중이면 자동으로 돌아갑니다. 직접 시키려면:

```
우리 병원 홈페이지 https://우리병원.com 을 seminar-min 프로파일로 수집해줘.
시술 이름이랑 가격은 홈페이지에 적힌 글자 그대로 가져오고, 페이지마다 원본을
파일로 남겨서 나중에 대조할 수 있게 해줘. 페이지에 있는 대표 사진 주소도 같이 모아줘.
15분 안에 끝내고, 시간이 모자라면 못 간 곳을 목록으로 남기고 거기서 끊어줘.
```

15분이 지나도 안 끝나면 이렇게 끊으시면 됩니다. 지금까지 받은 것만으로도 챗봇은
돌아갑니다.

```
지금까지 받은 것만으로 정리하고, 못 간 곳은 목록으로 남겨줘
```

홈페이지가 없는 병원이라면:

```
우리 병원은 홈페이지가 없어. 부산 서면에 있는 ○○의원이야. 강남언니 같은 데서
찾아서 수집해줘. 찾으면 주소랑 전화번호를 먼저 보여주고, 우리 병원이 맞는지
확인받고 진행해줘.
```

**기다리는 동안 할 일** 본인 홈페이지에서 시술 하나를 골라 가격을 적어두세요.
잠시 후 챗봇이 그 가격을 정확히 답하는지 대조할 겁니다.

### 수집 결과가 부실하면 — Claude가 여쭤봅니다

가격이 몇 개 안 나왔거나 진료시간·주차 같은 게 비어 있으면, Claude가 무엇이
비었는지 알려주고 몇 개씩 직접 물어봅니다. 말로 답하시면 그대로 들어가요.
확실하지 않은 건 그냥 "잘 모르겠다"고 하세요. 그 항목은 챗봇이
"확인 후 안내드리겠습니다"로 답하고, 나중에 대시보드에서 채우면 됩니다.

직접 시키고 싶다면:

```
수집한 것 중에 가격이나 진료시간이 빠진 게 뭔지 알려주고, 내가 불러줄 테니
몇 개씩 물어봐줘.
```

## 6. Laney에 넣기 (5분)

```
수집한 걸 Laney에 넣어줘. 시술이랑 상품은 나눠서 동시에 진행하고, 다 넣으면
저장된 이름을 수집 원본과 하나하나 대조해서 글자가 깨진 게 없는지 확인해줘.
모아둔 사진 주소는 시술에 붙이고, 메인페이지도 기본 구성으로 만들어줘.
```

끝나면 https://dashboard.laney.app 에 로그인해 보세요. Products 메뉴에 방금 넣은
시술들이 목록으로 보이면 성공입니다.

## 7. 챗봇에게 물어보기

세 가지를 순서대로 물어보세요.

먼저, 아까 적어둔 시술로. 홈페이지 가격과 똑같이 나오는지 봅니다.

```
울쎄라 가격 알려줘. 샷 수별로 옵션이 있으면 그것도 같이.
```

다음은 조건이 붙은 것. 요일 한정 이벤트가 있다면 챗봇이 방문 요일부터 되묻는지
보세요. (없는 병원은 "제일 저렴한 시술이 뭐야?"로 대신하세요)

```
화수목 이벤트 뭐 있어?
```

마지막이 가장 중요합니다. 홈페이지에 없는 걸 일부러 물어보는 겁니다.

```
강아지도 시술 받을 수 있어?
```

"확인이 어렵습니다"라고 답하면 성공입니다. 이상하게 들리겠지만, 모르는 걸
모른다고 하는 게 이 챗봇의 가장 중요한 기능입니다. 지어낸 답이 손님에게 나가는
순간 그 책임은 병원이 지게 되니까요.

## 8. 홈페이지에서 직접 보기

```
우리 병원 챗봇 홈페이지 링크 알려줘. 주소가 너무 길면 병원 이름으로 짧게 바꿔주고.
```

링크를 휴대폰으로 열어보세요. 오른쪽 아래 채팅에서 같은 질문을 다시 하면 같은
가격이 나옵니다. 같은 데이터를 보고 답하니까요. 첫 화면 인사말도 봐두세요,
바로 다음에 바꿉니다.

## 9. 말투를 우리 병원답게

```
챗봇 말투랑 첫인사를 우리 병원 분위기에 맞게 조정하고 싶어. 뭘 정해야 하는지
하나씩 물어봐줘.
```

첫마디를 뭐라고 할지, 답변은 짧게 할지 차근차근 할지, 호칭은 뭘로 할지.
Claude가 하나씩 물어봅니다. 말로 답하면 그대로 반영됩니다. 홈페이지 채팅을 새로
열어 확인하고, 마음에 들 때까지 반복하세요. 가격을 지어내지 않는 규칙은 말투를
어떻게 바꿔도 풀리지 않으니 안심하셔도 됩니다.

## 10. 예약도 받기 (시간이 남으면)

챗봇이 예약까지 잡아주게 하려면 두 가지를 정해야 합니다. 예약할 때 손님한테
무엇을 물어볼지, 그리고 언제 몇 명까지 받을지입니다.

```
챗봇이 예약도 잡아주게 하고 싶어. 예약할 때 뭘 받아야 하고 어떤 규칙을
정해야 하는지 하나씩 물어봐줘.
```

성함·연락처·희망 시술 같은 받을 정보를 먼저 정하고, 그다음 영업시간과 예약
간격(보통 30분), 같은 시간에 몇 명까지, 쉬는 날을 물어봅니다. 말로 답하시면
그대로 들어갑니다.

설정이 끝나면 챗봇에 직접 물어보세요. 네 가지를 순서대로 해보시면 됩니다.

```
이번 주 수요일에 울쎄라 예약 가능한 시간 알려줘
```

```
일요일에 예약할 수 있어?
```

쉬는 날은 "어렵다"고 답해야 정상입니다. 마지막으로 같은 시간에 두 번 예약을
걸어보세요. 두 번째는 막히거나 다른 시간을 제안해야 맞습니다.

연습으로 넣은 예약은 `방금 테스트로 넣은 예약 지워줘`로 정리됩니다.

## 11. 대시보드 구경 (시간이 남으면)

손님과 예약이 쌓이면 대시보드가 어떻게 되는지 미리 볼 수 있습니다.

```
대시보드 데모용 더미 데이터 넣어줘. 여러 나라 손님이랑 여러 채널에서 온 문의,
예약도 완료된 것 취소된 것 노쇼까지 상태별로 섞어서.
```

넣은 다음 "이번 달 예약 통계 내줘", "노쇼가 몇 건이야?", "채널별로 문의가 몇 건씩
왔어?" 같은 걸 물어보세요. 연습용 데이터는 `더미 데이터 지워줘` 한 마디로 깨끗하게
지워집니다.

## 뭔가 이상할 때

| 증상 | 이렇게 입력하세요 |
|---|---|
| 수집이 5분 넘게 조용하다 | `어디까지 됐는지 알려주고, 남은 것부터 이어서 해줘` |
| 시술이 몇 개 안 나왔다 | `우리 홈페이지는 가격이 사진으로 되어 있어. 사진도 읽어서 가져와줘` |
| 저장된 이름이 이상하다 | `저장된 이름이랑 수집 원본이랑 대조해서 다른 게 있으면 고쳐줘` |
| 처음부터 다시 하고 싶다 | `지금 들어간 시술이랑 상품 전부 지우고 처음부터 다시 해줘` |
| 지금 어디인지 모르겠다 | `다음 단계 알려줘` |

로그인이 안 되거나 남의 병원 데이터가 보이면, 만지지 말고 진행 요원을 불러주세요.
