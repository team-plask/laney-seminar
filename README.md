# Laney 세미나 — 우리 병원 챗봇 만들기

오늘 두 시간 동안 만드는 건 하나입니다. 우리 병원 홈페이지에 있는 시술과 가격을
그대로 알고, 없는 건 지어내지 않고 "확인 후 안내드리겠습니다"라고 답하는 상담 챗봇.
코딩은 없습니다. 아래 회색 상자들을 순서대로 복사해서 붙여넣는 게 전부입니다.

회색 상자에 마우스를 올리면 오른쪽 위에 복사 버튼이 생깁니다.

## 두 가지 진행 방법

**직접 물어보며 가기** — 도구 설치(1번)와 승인 설정(2번)만 마치면 바로 시작할 수
있습니다. 클로드 코드가 권장하는 "계획 먼저" 방식입니다.

가능하면 입력창에서 **플랜 모드**로 바꾸세요(키보드 Shift+Tab을 누르면 모드가
바뀝니다). 못 찾아도 괜찮습니다 — 아래 문장 자체가 계획부터 세우게 되어 있습니다.

병원 이름과 홈페이지 주소만 본인 것으로 바꿔서 입력하세요:

```
지금부터 레이니(Laney)로 우리 병원의 상담 챗봇과 홈페이지를 만들려고 해.

우리 병원: ○○의원 (부산 서면)
홈페이지: https://우리병원.com

바로 실행하지 말고, 먼저 이렇게 해줘:
1. 레이니가 어떤 구조인지, 챗봇이 되려면 최소한 뭐가 필요한지 파악하고
2. 지금 내 레이니 연결 상태와 병원 공간이 비어 있는지 확인해줘.
   아직 연결 전이면 가입·연결부터 계획의 1단계로 넣어줘.
3. 그다음 데이터를 어디서 모아서, 무엇을, 어떤 순서로 넣을지 전체 계획을 세워줘.

계획에는 단계마다 예상 시간과, 끝났을 때 내가 눈으로 확인할 것을 같이 적어줘.
지켜야 할 원칙: 홈페이지에 적힌 것만 쓰고, 가격은 글자 그대로 옮기고,
챗봇은 모르는 걸 절대 지어내지 않아야 해.
계획을 보여주면 내가 읽고 승인한 다음에 시작하자.
```

(홈페이지가 없으면 `홈페이지: 없음 — 강남언니에서 찾아줘` 로 바꾸세요)

Claude가 계획을 내놓으면 읽어보세요. 대략 이런 모양이면 정상입니다:
가입·연결 → 홈페이지 수집(15분) → 수집 결과 검증 → 가격표와 챗봇 성격 입력(5분)
→ 챗봇 테스트 → 홈페이지 링크 → 말투 다듬기. 이상한 단계가 있으면 그 자리에서
"이건 왜 해?"라고 물으면 되고, 마음에 들면:

```
좋아, 계획대로 진행해줘. 단계가 끝날 때마다 결과를 보여주고 이어가.
```

중간에 궁금한 건 언제든 물어보세요 — "레이니가 뭐야?", "엔티티가 뭔데?",
"지금 어디까지 됐어?" 전부 답합니다.

**차례대로 가기** — 아래 1번부터 10번까지 순서대로 복사해 넣는 코스입니다.
어느 쪽으로 가든, 막히면 `다음 단계 알려줘` 한 줄이면 됩니다.

## 시작하기 전에 — Windows 노트북이라면

Claude Code가 동작하려면 프로그램 두 개가 먼저 필요합니다. 키보드에서 Windows 키를
누르고 "PowerShell"을 입력해 파란 창을 연 다음, 아래 한 줄을 붙여넣고 Enter를 누르세요.
2~3분 걸립니다. 끝나면 창을 닫으면 됩니다. Mac은 이 단계가 필요 없습니다.

```powershell
winget install --id Git.Git -e --source winget; irm https://claude.ai/install.ps1 | iex
```

그다음 https://claude.com/claude-code 에서 Claude Code 앱을 설치하고,
Claude 계정으로 로그인한 뒤, 새 폴더를 하나 만들어(이름은 아무거나) 세션을 여세요.

## 1. 도구 설치

Claude에게 말하듯 입력하면 Claude가 알아서 설치합니다.
중간에 허용 버튼이 한두 번 뜨는데, 눌러주시면 됩니다.

```
team-plask/laney-seminar 마켓플레이스를 추가하고, laney-seminar 플러그인을 설치해줘.
설치가 끝나면 어떤 스킬이 들어왔는지 알려줘.
```

## 2. 허용 버튼 그만 누르기

이대로 진행하면 단계마다 허용 버튼을 눌러야 해서 번거롭습니다. 한 번만 설정해두면
그 뒤로는 안 뜹니다.

```
~/.claude/settings.json 파일을 만들어줘. 내용은 이거야:
{ "permissions": { "defaultMode": "bypassPermissions" },
  "skipDangerousModePermissionPrompt": true }
```

허용 버튼이 마지막으로 한 번 뜹니다. 누른 다음 **앱을 완전히 껐다가 다시 켜세요.**
같은 폴더로 세션을 다시 열면 됩니다.

## 3. 길잡이

지금부터는 길을 잃을 때마다 이 한 줄만 기억하시면 됩니다. 어느 단계에 있든,
지금 어디까지 왔고 다음에 뭘 하면 되는지 Claude가 확인해서 알려줍니다.

```
다음 단계 알려줘
```

## 4. Laney 가입하고 연결하기

```
Laney에 연결해줘
```

브라우저가 열립니다. 회원가입을 선택하고 이메일과 비밀번호를 만드세요.
**병원 이름은 정확하게 입력해 주세요** — 이 이름으로 병원 공간이 만들어지고,
챗봇과 홈페이지에 그대로 쓰입니다.

가입하면 확인 메일이 옵니다. 휴대폰 메일함에서 열어도 됩니다. 링크를 누르면
로그인 화면이 하나 뜨는데, 인증은 이미 끝난 것이니 그 창은 닫아도 됩니다.
Claude로 돌아와서 다시 한 번:

```
Laney에 연결해줘
```

이번에는 방금 만든 계정으로 로그인하면 연결이 됩니다. 잘 됐는지 확인해봅시다.

```
연결 확인해줘. 우리 병원 이름이 뭐라고 나오는지, 그리고 지금 등록된 시술이랑
상품이 몇 개인지 알려줘.
```

병원 이름이 맞고 시술·상품이 0개면 정상입니다. 방금 만든 빈 공간이니까요.
만약 0이 아니라면 진행하지 말고 손을 들어주세요.

## 5. 우리 병원 수집

주소만 본인 병원 것으로 바꿔서 입력하세요. 15분쯤 걸립니다.

```
우리 병원 홈페이지 https://우리병원.com 을 seminar-min 프로파일로 수집해줘.
시술 이름이랑 가격은 홈페이지에 적힌 글자 그대로 가져오고, 페이지마다 원본을
파일로 남겨서 나중에 대조할 수 있게 해줘. 페이지에 있는 대표 사진 주소도 같이 모아줘.
```

홈페이지가 없는 병원이라면 대신 이렇게 입력하세요. 강남언니와 구글 지도에서
찾아서 진행하고, 가격은 강남언니에 올리신 기준으로 답하게 됩니다.

```
우리 병원은 홈페이지가 없어. 부산 서면에 있는 ○○의원이야. 강남언니 같은 데서
찾아서 수집해줘. 찾으면 주소랑 전화번호를 먼저 보여주고, 우리 병원이 맞는지
확인받고 진행해줘.
```

기다리는 동안 할 일이 하나 있습니다. 본인 홈페이지에서 시술 하나를 골라
가격을 적어두세요. 잠시 후에 챗봇이 그 가격을 정확히 답하는지 대조할 겁니다.

## 6. Laney에 넣기

수집이 끝나면 가져온 걸 병원 공간에 넣습니다. 5분쯤 걸립니다.

```
수집한 걸 Laney에 넣어줘. 시술이랑 상품은 나눠서 동시에 진행하고, 다 넣으면
저장된 이름을 수집 원본과 하나하나 대조해서 글자가 깨진 게 없는지 확인해줘.
모아둔 사진 주소는 시술에 붙이고, 메인페이지도 기본 구성으로 만들어줘.
```

끝나면 브라우저에서 https://dashboard.laney.app 에 로그인해 보세요.
상품 메뉴에 방금 넣은 시술들이 목록으로 보이면 성공입니다.

## 7. 챗봇에게 물어보기

이제 만든 챗봇을 시험할 차례입니다. 세 가지를 순서대로 물어보세요.

먼저, 아까 적어둔 시술로 — 홈페이지 가격과 똑같이 나오는지 보세요.

```
울쎄라 가격 알려줘. 샷 수별로 옵션이 있으면 그것도 같이.
```

다음은 조건이 붙은 것. 요일 한정 이벤트가 있다면 챗봇이 방문 요일부터
되묻는지 보세요. (없는 병원은 "제일 저렴한 시술이 뭐야?"로 대신하세요)

```
화수목 이벤트 뭐 있어?
```

마지막이 가장 중요합니다. 홈페이지에 없는 걸 일부러 물어보는 겁니다.

```
강아지도 시술 받을 수 있어?
```

"확인이 어렵습니다"라고 답하면 성공입니다. 이상하게 들리겠지만, 모르는 걸
모른다고 하는 게 이 챗봇의 가장 중요한 기능입니다. 아는 척하고 지어낸 답이
손님에게 나가는 순간, 그 책임은 병원이 지게 되니까요.

## 8. 홈페이지에서 직접 보기

```
우리 병원 챗봇 홈페이지 링크 알려줘. 주소가 너무 길면 병원 이름으로 짧게 바꿔주고.
```

링크를 휴대폰으로 열어보세요. 오른쪽 아래 채팅에서 방금 했던 질문들을 다시
해보면, 같은 가격이 나옵니다. 같은 데이터를 보고 답하니까요. 첫 화면에 나오는
인사말도 봐두세요 — 바로 다음에 바꿀 겁니다.

## 9. 말투를 우리 병원답게

```
챗봇 말투랑 첫인사를 우리 병원 분위기에 맞게 조정하고 싶어. 뭘 정해야 하는지
하나씩 물어봐줘.
```

첫마디를 뭐라고 할지, 답변은 짧게 할지 차근차근 할지, 호칭은 뭘로 할지 —
Claude가 하나씩 물어봅니다. 편하게 말로 답하면 그대로 반영됩니다. 홈페이지
채팅을 새로 열어 확인하고, 마음에 들 때까지 반복하세요. 가격을 지어내지 않는
규칙 같은 건 말투를 어떻게 바꿔도 풀리지 않으니 안심하셔도 됩니다.

## 10. 대시보드 구경 (시간이 남으면)

손님과 예약이 쌓이면 대시보드가 어떻게 되는지 미리 볼 수 있습니다.

```
대시보드 데모용 더미 데이터 넣어줘. 여러 나라 손님이랑 여러 채널에서 온 문의,
예약도 완료된 것 취소된 것 노쇼까지 상태별로 섞어서.
```

넣은 다음 대시보드에서 "이번 달 예약 통계 내줘", "노쇼가 몇 건이야?",
"채널별로 문의가 몇 건씩 왔어?" 같은 걸 물어보세요. 연습용 데이터는
"더미 데이터 지워줘" 한 마디로 깨끗하게 지워집니다.

## 뭔가 이상할 때

수집이 5분 넘게 조용하면 — `어디까지 됐는지 알려주고, 남은 것부터 이어서 해줘`

시술이 몇 개 안 나왔다면 홈페이지 가격이 사진으로 올라가 있을 가능성이 큽니다 —
`우리 홈페이지는 가격이 사진으로 되어 있어. 사진도 읽어서 가져와줘`

저장된 이름이 이상하면 — `저장된 이름이랑 수집 원본이랑 대조해서 다른 게 있으면 고쳐줘`

아예 처음부터 다시 하고 싶으면 — `지금 들어간 시술이랑 상품 전부 지우고 처음부터 다시 해줘`

로그인이 안 되거나 남의 병원 데이터가 보이면, 만지지 말고 진행 요원을 불러주세요.
