# Laney 세미나 — 병원 챗봇 만들기

우리 병원 홈페이지에 **공개된 정보만** 수집해서, 상담 챗봇이 우리 병원 시술과
가격으로 답하게 만듭니다. 아래를 **위에서부터 순서대로** 따라 하시면 됩니다.

각 회색 상자 오른쪽 위의 **복사 버튼(⧉)** 을 누르면 그대로 복사됩니다.

## 한눈에 보기 — 오늘 입력할 전부

| # | 하는 일 | 입력 |
|---|---|---|
| 0 | (Windows만) 사전 설치 | PowerShell 한 줄 — 유일한 터미널 사용 |
| 1 | 플러그인 설치 | `…마켓플레이스를 추가하고, laney-seminar 플러그인을 설치해줘` |
| 2 | 승인창 끄기 | 설정 파일 프롬프트 → **앱 재시작** |
| 3 | 길잡이 켜기 | `다음 단계 알려줘` ← 막히면 언제나 이것 |
| 4 | 가입 + 연결 | `Laney에 연결해줘` → 회원가입 → 메일 인증 → 다시 연결 |
| 5 | 확인 | 병원 이름 확인 / 시술·상품 **0개** 확인 |
| 6 | 수집 (~15분) | 우리 병원 홈페이지 수집 프롬프트 |
| 7 | 입력 (~5분) | Laney에 넣기 프롬프트 |
| 8 | 테스트 | 가격 → 화수목 → "강아지도 되나요?" 3문장 |
| 9 | 홈페이지 챗봇 | `우리 병원 챗봇 홈페이지 링크 만들어줘` → 같은 질문 재확인 |
| 10 | 말투 조정 | `챗봇 말투랑 첫인사를 조정하고 싶어` → 대화로 답하면 반영 |

터미널은 0단계 한 번뿐, 나머지는 전부 Claude에게 말하는 문장입니다.
아래에 각 단계의 복사할 문장이 순서대로 있습니다.

---

## 0. 준비 — Windows이신 경우 먼저 (Mac은 건너뛰세요)

키보드 **Windows 키 → "PowerShell" 입력 → Enter** → 아래 한 줄 붙여넣고 Enter
→ 끝날 때까지 대기(2~3분) → 창 닫기:

```powershell
winget install --id Git.Git -e --source winget; irm https://claude.ai/install.ps1 | iex
```

그다음 **Claude Code 앱** 설치: https://claude.com/claude-code
앱을 열고 Claude 계정으로 로그인 → 새 폴더(예: `laney-seminar`)를 만들어 세션을 엽니다.

## 1. 플러그인 설치 — Claude에게 말하듯 입력

```
team-plask/laney-seminar 마켓플레이스를 추가하고, laney-seminar 플러그인을 설치해줘
```

중간에 **허용 버튼**이 한두 번 뜨면 눌러주세요.
끝나면 "설치됐다"는 답과 함께 스킬 4개가 확인됩니다.

## 2. 승인창 끄기

```
~/.claude/settings.json 파일을 만들어줘. 내용은 이거야:
{ "permissions": { "defaultMode": "bypassPermissions" },
  "skipDangerousModePermissionPrompt": true }
```

승인창이 **한 번** 뜨면 허용 → **앱을 완전히 껐다가 다시 켭니다.**

## 3. 길잡이 켜기 — 막히면 언제나 이 문장

```
다음 단계 알려줘
```

지금 어디까지 됐는지 확인하고 다음 할 일을 안내판으로 보여줍니다.
**이후 어느 단계에서든 헷갈리면 이 문장부터 입력하세요.**

## 4. Laney 가입 + 연결

```
Laney에 연결해줘
```

브라우저가 열리면 **회원가입** (계정이 있으면 로그인):
- **병원 이름을 정확히 입력하세요** — 그 이름으로 병원 공간이 만들어집니다
- 가입 후 **확인 메일**이 옵니다 → 메일함에서 링크 클릭 (휴대폰도 됩니다)
- 링크를 누르면 로그인 화면이 하나 뜨는데 **그 창은 닫으셔도 됩니다** (인증은 이미 완료)

다시:

```
Laney에 연결해줘
```

이번엔 로그인 → 연결 완료. 확인:

```
연결 확인해줘. 우리 병원 이름이 뭐라고 나와?
```

```
지금 우리 조직에 등록된 시술이랑 상품이 몇 개인지 알려줘
```

→ **둘 다 0개가 정상입니다.** (0이 아니면 진행하지 말고 담당자에게 알려주세요)

## 5. 수집 — 약 15분

주소만 본인 병원으로 바꿔서:

```
우리 병원 홈페이지 https://우리병원.com 을 seminar-min 프로파일로 수집해줘
```

기다리는 동안, 본인 홈페이지에서 시술 하나의 가격을 골라 적어두세요. (다음 단계 대조용)

**홈페이지가 없으신 경우** — 대신 이렇게 입력하세요:

```
홈페이지가 없는 병원이야. 부산 서면 ○○의원 을 찾아서 수집해줘
```

강남언니·구글 지도에서 찾아 진행하고, 가격은 강남언니에 올리신 기준으로 답하게 됩니다.

## 6. Laney에 넣기 — 약 5분

```
수집한 걸 Laney에 넣어줘.
엔티티랑 상품은 나눠서 동시에 진행하고, 넣은 다음에 이름이 안 깨졌는지 확인해줘
```

끝나면 브라우저에서 **https://dashboard.laney.app** → 상품 메뉴 →
방금 넣은 상품들이 보이면 성공입니다.

## 7. 테스트 — 세 가지를 순서대로

```
울쎄라 가격 알려줘
```

→ 아까 적어둔 홈페이지 가격과 같은지 확인하세요.

```
화수목 이벤트 뭐 있어?
```

→ 방문 요일을 먼저 되물으면 정상입니다.

```
강아지도 시술 받을 수 있어?
```

→ **"확인이 어렵습니다"가 정답입니다.** 모른다고 답하는 건 고장이 아니라,
틀린 답을 지어내지 않도록 만든 결과입니다.

## 8. 우리 병원 챗봇 홈페이지에서 직접

```
우리 병원 챗봇 홈페이지 링크 만들어줘
```

링크가 나오면 (휴대폰으로도) 열어서, 방금 했던 세 가지 질문을 **홈페이지 채팅에서**
다시 해보세요. 가격이 똑같이 나오면 성공입니다 — 같은 데이터를 보고 답하니까요.
첫 화면의 **시작 인사말**도 봐두세요. 다음 단계에서 바꿉니다.

## 9. 챗봇 말투를 우리 병원답게

```
챗봇 말투랑 첫인사를 조정하고 싶어
```

Claude가 하나씩 물어봅니다 — 첫마디를 뭐라고 할지, 답변을 짧게 할지 길게 할지,
호칭은 뭘로 할지. **편하게 말로 답하시면** 그대로 반영되고, 홈페이지 채팅을
새로 열면 바뀐 말투로 인사합니다. 마음에 들 때까지 반복하세요.

## 문제가 생기면

| 상황 | 이렇게 입력하세요 |
|---|---|
| 어디까지 됐는지 모르겠다 | `다음 단계 알려줘` |
| 수집이 조용하다 (5분+) | `어디까지 됐는지 알려주고, 남은 것부터 이어서 해줘` |
| 가격이 사진으로만 있다 | `우리 홈페이지는 가격이 사진으로 되어 있어. 사진도 읽어서 가져와줘` |
| 이름이 이상하게 저장됐다 | `저장된 이름이랑 수집 원본이랑 대조해서 다른 게 있으면 고쳐줘` |
| 처음부터 다시 하고 싶다 | `지금 들어간 시술이랑 상품 전부 지우고 처음부터 다시 해줘` |

## 알아두실 점

- 이 과정은 **우리 병원 홈페이지에 공개된 정보만** 가져옵니다.
- 홈페이지에 **정가 표기가 없으면 할인율을 만들지 않습니다.**
- 수집한 모든 내용은 원문 파일로 남습니다 — 근거 없는 정보는 들어가지 않습니다.
